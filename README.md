# Chip Tuning Telegram Bot

Telegram-бот каталога чип-тюнинга.

## Возможности

- `/start` — главное меню.
- `/list` — полный каталог автомобилей.
- Поиск по марке, модели и двигателю.
- Карточка автомобиля: сток → Stage 1, мощность, момент, прирост, ориентировочная цена.
- График мощности/момента.
- Ссылки на исходную карточку AVT.
- Ориентировочные цены ADACT по маркам.
- Автоматическое обновление каталога по расписанию.

## Запуск

Нужна переменная окружения `BOT_TOKEN`.

Для Railway:
1. Создать сервис из этого GitHub-репозитория.
2. Добавить Variable `BOT_TOKEN` со значением токена от BotFather.
3. Deploy.

Бот не содержит токен в исходниках.

## Источники

- AVT: https://avt.ru/catalog/
- ADACT: https://adact2.ru/

Данные показываются как ориентировочные. Перед публикацией коммерческих предложений рекомендуется проверять актуальные цены и характеристики на исходном сайте.
